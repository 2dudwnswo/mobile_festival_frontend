# 축제 주점 관리자 앱 (Android · Kotlin)

```
festival-pub/
├─ android/        ← 관리자 앱 (Android Studio로 열기)
├─ mock-server/    ← 친구 서버가 나오기 전 테스트용 임시 서버 (Node.js)
└─ docs/API.md     ← 친구와 맞출 서버 API·WebSocket 명세
```

## 1. 테스트 서버 실행 (노트북)

1. Node.js(LTS) 설치: https://nodejs.org
2. 터미널에서:
   ```
   cd mock-server
   npm install
   npm start
   ```
3. 출력되는 `앱 서버 주소: http://192.168.x.x:8080`를 앱에 입력합니다.
4. 손님 역할 테스트: 브라우저로 `http://192.168.x.x:8080/dev` 접속 → 웨이팅 등록 / QR 주문 흉내.
   같은 페이지의 **입금 대기 주문** 목록에서 [입금확인(서버 흉내)]를 누르면, 서버가 입금을 확인한 것처럼 주문이 `PAID`가 되어 앱에 나타납니다.

> 폰과 노트북이 **같은 와이파이(핫스팟)** 에 있어야 합니다. Windows 방화벽이 8080 포트를 막으면 "허용"을 눌러 주세요.

## 2. 앱 실행

1. Android Studio(최신 버전)에서 `android` 폴더 열기 → Gradle 동기화가 끝날 때까지 대기
2. 폰에서 개발자 옵션 → USB 디버깅 켜고 연결 → ▶ Run
3. 스태프 폰에 배포할 APK: 메뉴 **Build → Build APK(s)** → `app/build/outputs/apk/debug/app-debug.apk` 를 카톡/USB로 전달해서 설치

첫 실행 시 **전화 권한 허용** → 웨이팅 맨 위 팀을 탭하면 확인 없이 바로 발신됩니다.

## 3. 화면 구성

| 탭 / 화면 | 기능 |
|---|---|
| 1-O 접속·담당자 | 서버 주소 입력(저장됨), 담당자 선택. 앱 실행할 때마다 선택 |
| 1-1 테이블 | 웹서버에서 받은 가로×세로 격자 그대로 표시, 색상(빈자리/이용중/임박/초과), 남은 시간 |
| 1-2 테이블 상세 | 빈자리: 웨이팅 팀 배정 또는 현장 손님 착석 → **착석 순간 100분 타이머 시작**. 이용중: 연장 +10/20/30, 주문 내역과 주문 합계(입금확인된 주문만), 이용 종료 |
| 1-3 웨이팅 | VIP 맨 위, 일반은 등록순. **맨 위 팀 탭하면 바로 전화**, 호출 후 3분이 지나면 [무응답] 버튼. 무응답 팀은 아래쪽에 흐리게 표시 |
| 1-4 웨이팅 상세 | 전화, 빈 테이블 번호 눌러 착석 배정, 무응답 처리, 대기 복귀, 취소 |
| VIP 등록 | 웨이팅 탭 우측 하단 버튼 |
| 1-5 주문 입력 | QR 주문의 예비 수단. 테이블 → 메뉴 → 수량 → 전송(확인창). 직원 주문도 QR 주문처럼 서버가 입금을 확인해야 주방으로 감 |
| 1-6 주방 | **서버가 입금확인한 주문만** 입금 순서대로. 새 주문이 들어오면 짧은 알림음. 15분 넘으면 빨간색. 조리완료(확인창, 되돌릴 수 없음) |
| 1-S 설정 (⚙) | 테이블 배치 보기(웹서버에서 관리, 앱에서는 수정 불가), 회전/임박/무응답 시간, 서버 주소, 담당자 변경 |

알림: 테이블이 초과되면 진동+소리, 정리될 때까지 1분마다 반복. 임박이 되면 짧은 진동 1회.
화면은 행사 중 꺼지지 않도록 설정되어 있습니다.

## 4. 반영된 결정 사항

- 회전 100분, 타이머는 **착석 순간** 시작 (결제와 무관)
- 주문은 테이블 QR로 받고, **주문마다 선결제** → **입금확인은 서버가 판단**하고, 앱에는 입금확인된 주문만 나타남 (앱은 입금확인·주문취소를 하지 않음)
- 빈 테이블에서 들어온 QR 주문은 서버가 거절
- VIP는 일반 손님 "내 앞 대기" 계산에서 제외 (순번이 뒤로 밀리지 않음)
- 무응답: 호출 후 3분이 지나면 스태프가 수동 처리, 늦게 오면 원래 순서로 복귀
- 테이블 배치(가로×세로, 개수)는 웹서버에서 관리하고, 앱은 받아서 보여주기만 함
- 테이블 번호는 1번부터 고정 (QR 번호와 같음)
- 서버는 핫스팟에 연결된 노트북에서 실행
